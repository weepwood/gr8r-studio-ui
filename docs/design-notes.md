# 设计研究与实现说明

本项目把 Gr8r Studio 作为界面风格研究对象，提炼可复用设计规则，不直接移植其组件源码。

## 设计原则

1. **中性分层**：内容画布、侧栏、卡片以轻微明度差分隔，减少冗余边框。
2. **信息密度可控**：紧凑型控制高度、明确的表格行节奏和统一的排版层级。
3. **色彩按语义分配**：强调色仅用于主操作、选中状态、焦点；成功 / 警告 / 危险单独表达。
4. **低干扰动效**：悬停、弹层和状态切换较轻；适配 `prefers-reduced-motion`。
5. **可组合结构**：任务行、看板列、卡片、状态标记、团队头像作为独立呈现层。
6. **键盘优先**：可操作组件使用原生语义元素、ARIA 属性和可见的焦点。

## 技术决策

- 原生 CSS + ES modules + Web Components，让 Vue / React / HTML 项目共用同一视觉语言。
- 所有样式类使用 `gr-` 前缀，根容器为 `.gr-ui`；降低宿主冲突。
- Design Tokens 使用 `--gr-*` 自定义属性；主题属性放在实际的组件根节点。
- `src/` 为可发布库，`demo/` 与 `index.html` 仅用于独立展示。
- 未纳入数据库、账号系统、同步、持久化或真正的看板拖拽引擎。

## 后续可扩展方向

复杂 Combobox / DatePicker、虚拟列表、React/Vue 包装层、Playwright + axe 回归测试、Figma Tokens 导出、更多业务组合。
