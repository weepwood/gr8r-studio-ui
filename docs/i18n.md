# 本地化（zh-CN）说明

日期：2026-11-23 · 版本：0.4.0

## 分层

| 层 | 负责什么 | 实现 |
| --- | --- | --- |
| 组件库 | 组件**自己生成**的文字：无障碍名称、空状态、看板读屏播报、日历按钮与月份 | `src/i18n.js`，每个元素的 `localize()`，`applyGr8rLocale()` |
| 应用（展示站） | 页面上作者写的文字、`aria-label`、占位符、动态提示 | `demo/i18n.js`：`PHRASES`（按英文原文翻译静态 HTML）+ `MESSAGES`（按键翻译动态文字） |

组件不会翻译你传进来的内容（选项文字、标签、`aria-label`），这些属于应用。

## 语言选择规则

1. 已保存的选择（`gr8r-gallery:v1` 中的 `preferences.locale`）；
2. 否则取浏览器首选语言：`zh`、`zh-CN`、`zh-Hans`、`zh-TW` 等都视为简体中文，其他为英文；
3. 页面在首次绘制前设置 `<html lang>`；中文时先隐藏主界面，翻译完成后显示（最长 1.5 秒兜底，脚本失败也不会一直空白）。

## 翻译方式

- **静态文字**：`translateTree()` 遍历文本节点及 `aria-label / placeholder / data-gr-tooltip / data-toast / label / title`，按原文精确匹配 `PHRASES`。中英文一一对应（测试保证没有两个英文共用同一个中文），因此可以无损切回英文，HTML 保持为普通英文标记。
- **不翻译**：`pre / code / kbd / .gr-kbd`、Code 视图、`[data-i18n-skip]`（用户输入的任务标题与描述、文件名、表单值、语言名称本身）。
- **动态文字**：`t(key, vars)`，例如 `已完成 {done} / {total}`、通知、按钮的无障碍名称、看板日志。
- **示例数据**：未修改过的示例任务会随语言替换为对应语言版本（同 ID、同枚举）；任何修改过的任务保持原样。
- **表单值**：下拉选项使用固定 `value`，切换语言不改变提交的数据。

## 术语

| English | 中文 | English | 中文 |
| --- | --- | --- | --- |
| Backlog | 待规划 | Priority | 优先级 |
| To do | 待办 | Urgent / High / Medium / Low | 紧急 / 高 / 中 / 低 |
| In progress | 进行中 | Assignee | 负责人 |
| Review | 评审 | Due date | 截止日期 |
| Done | 完成 | Drawer | 抽屉 |
| Completed（状态描述） | 已完成 | Toast | 通知 |
| Board / List / Table | 看板 / 列表 / 表格 | Command palette | 命令面板 |
| Reduce motion | 减少动效 | Follow system | 跟随系统 |

中文文案使用全角标点；中英文之间保留空格（如“12 个 Web Components”）；按键名（Space、Escape、Shift F10）保持英文。

## 新增文案时

1. 在 `index.html` 写英文；
2. 在 `demo/i18n.js` 的 `PHRASES` 中加入对应中文（`npm test` 会列出所有缺失的翻译）；
3. 脚本生成的文字加到 `MESSAGES.en` 与 `MESSAGES["zh-CN"]`（测试检查两边键和占位符一致）。

## 尚未覆盖

- Code 视图中的示例 HTML、API 表里的技术说明（类型、事件 detail）保持英文；
- 只提供简体中文，繁体中文用户会看到简体；
- 未进行母语读屏器（VoiceOver 中文、NVDA 中文）人工测试。
