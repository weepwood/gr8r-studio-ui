# v0.3：设计、交互与动效完善

日期：2026-11-23  
目标：继续从 [gr8rstudio/gr8r-studio](https://github.com/gr8rstudio/gr8r-studio) 提取**可复用的组件与交互模式**（独立重写，不复制源码），并让展示站真正可以“看、试、抄”。

## 一、从原项目提取了什么

原项目是一个完整的项目管理应用（Board / List / Table / Calendar / Timeline、任务抽屉、弹出选择器、右键菜单、拖放、命令面板）。本轮把其中**与业务数据无关、可以独立复用**的部分抽成组件：

| 原项目中的模式 | 本库实现 | 说明 |
| --- | --- | --- |
| 状态 / 优先级 / 负责人 / 日期弹出选择 | `gr-popover` + listbox / `gr-calendar` | 同一个浮层组件，内容决定行为 |
| 设计系统化的 select 下拉 | `gr-select` | 原生 select 仍是数据源 |
| 任务右键菜单 | `gr-context-menu` | 支持键盘调出 |
| 任务详情抽屉 | `gr-drawer` | 复用 `gr-dialog` 的焦点与关闭逻辑 |
| 看板拖放 | `gr-kanban` | 补上原项目缺少的键盘替代与读屏播报 |
| 状态圆环、优先级柱、标签色 | `gr-status`、`gr-priority`、`gr-tag--*` | 纯 CSS，图形 + 文字 |
| 顶部指标条、提示条、过滤标签、面包屑 | `gr-stat-group`、`gr-alert`、`gr-chip`、`gr-breadcrumbs` | 纯 CSS |
| 完成 / 新增 / 落位等一次性动效 | `motion.css` 的 `gr-fx-*` | 由类名触发，便于任何框架复用 |

没有提取的：路由、store、种子数据、协作 / 评论、时间线依赖计算等应用层逻辑——它们属于产品而不是组件库。

## 二、设计

- **层级克制**：卡片静止时只有细线与极浅阴影；只有“在动的东西”（浮层、拖动中的卡片）才有明显投影。新增 `--gr-shadow-card / hover / drag` 三级。
- **状态不只靠颜色**：状态用圆环填充程度（空 → 半 → 3/4 → 实心勾）、优先级用柱高，并始终配文字。
- **新增 3 个标签色**（teal / rose / orange），在浅色、深色、跟随系统三种主题、三种表面上都 ≥ 4.5:1，并有自动化测试。
- **跟随系统主题**用纯 CSS 实现（`@media (prefers-color-scheme: dark)` 镜像深色变量），首屏无闪烁；测试保证 system 与 dark 变量不漂移。

## 三、交互

| 组件 | 鼠标 / 触屏 | 键盘 | 辅助技术 |
| --- | --- | --- | --- |
| Popover 选择器 | 点击打开，外部点击关闭 | ↓ 打开；↑↓ Home End、首字母、Enter、Esc 回焦；过滤框 ↓ 进入列表 | listbox / option / aria-selected |
| Select | 点击打开 | APG select-only combobox：↑↓ PageUp/Down、连续输入、Tab 确认 | combobox + aria-activedescendant |
| Context menu | 右键 | ContextMenu 键 / Shift+F10 | menu / menuitem，关闭回焦 |
| Calendar | 点击日期 | 方向键、Home/End、PageUp/Down（Shift = 年） | aria-current="date"、完整日期名称 |
| Kanban | 拖动（触屏长按 260 ms） | Space 拿起、方向键移动、Space 放下、Esc 取消 | aria-live 播报列名与位置 |
| Drawer | 点击遮罩关闭 | Esc、焦点受限与回焦 | 原生 modal dialog |

所有浮层使用原生 Popover API 进入顶层（不被 `overflow` / `transform` 裁切），不支持时回退到 `hidden`；关闭逻辑在组件内统一实现，两种模式行为一致。`gr-move`、`gr-select` 等事件可取消，便于做流程校验（展示站示例：未经 Review 的卡片不能直接拖到 Done）。

## 四、动效原则

1. **只为状态变化服务**：新增、完成、移动、删除、校验失败各有一个一次性效果；不做循环装饰（测试禁止 `infinite`）。
2. **短**：hover / 按压 120 ms，菜单 / 弹层 140–200 ms，抽屉 210–320 ms；弹簧只用于“确认感”（打勾、落位、开关）。
3. **可中断**：菜单、抽屉、Toast 使用过渡或可中断属性；菜单入场用独立的 `translate` / `scale`，不覆盖视口修正用的 `transform`。
4. **空间连续**：看板拖动时其他卡片用 FLIP 让位，松手后卡片从拖影处滑入槽位；Tabs 指示条在标签间滑动。
5. **高频界面不动**：命令面板行、菜单项、列表滚动不加逐项动画。
6. **永远可关闭**：系统 `prefers-reduced-motion` 与应用内 `data-gr-motion="reduce"` 都会把效果降级为 120 ms 淡入或直接跳过。

## 五、展示站

- 每张组件卡片：**Preview / Code / API**。Code 取自组件升级前的原始 HTML（去掉展示站专用的 `data-toast` 等属性），API 列出用到的 CSS 类以及 Web Component 的属性 / 事件 / 方法。

- 外观：Light / Dark / System、强调色、密度、减少动效；在首个绘制前应用已保存的偏好。

## 六、验证与限制

- Node 测试：28 项（原有 + 新增 `test/v03-components.test.mjs`）在本次修改中通过；`test/pages-artifact.test.mjs` 未改动。
- 新增 `e2e/v03.spec.js`（看板键盘 / 拖放 / 取消、Select、选择器、右键菜单、抽屉、偏好持久化、Code 视图、小屏溢出）。**本轮未在真实浏览器中运行 Playwright**，请在本地或 CI 执行 `npm run check:all` 确认。
- 原生 Popover API 需要 Chrome 114+ / Safari 17+ / Firefox 125+；更早的浏览器使用 `hidden` 回退（浮层可能被带 `transform` 的祖先裁切）。`linear()` 弹簧曲线不支持时回退为 cubic-bezier。
- 未做 VoiceOver / NVDA 人工测试与完整 WCAG 审计。
